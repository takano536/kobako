# UI レイアウト規則

## 画面の順序

月単位で表示する概要・取引画面は、次の順序を共通にします。

1. グローバルヘッダー
2. `PageHeader`（ページの `h1`、必要なら件数、右側のアクション）
3. `MonthSwitcher`
4. 画面固有の操作（取引画面では `FilterBar` と現在の絞り込み条件）
5. 本文

`MonthSwitcher` は月移動のリンクを持つ `nav` です。中央の月表示は見出しではなく、`aria-live` も付けません。概要では月だけを、取引では `month`・`type`・`category` を次月・前月の URL に引き継ぎます。画面幅が狭くなってもこの順序を変えず、条件概要は折り返して横スクロールを発生させません。

残高画面は月切替を持たず、次の順序にします。

1. グローバルヘッダー
2. `PageHeader`（ページの `h1`）
3. 残高の集計（資産・負債・純資産）
4. 口座別の残高一覧
5. 集計条件の注記

残高一覧の口座名は保存値のまま折り返し、金額は同じ列で右揃えにします。口座行は操作や詳細画面へのリンクにせず、ホバー時の操作 affordance も持ちません。集計は全期間を対象とし、未来日付の取引を含みます。初期残高は反映せず、口座未指定の取引は除外します。

## 共通コンポーネントとアクション

共通部品は `apps/web/app/_components/ui.tsx` に置きます。

- `PageShell`: wide（58rem）、narrow（42rem）、import（44rem）のページ幅を提供します。
- `PageHeader`: ページの `h1` を一つだけ持ち、アクション群を右側に置きます。概要・取引では h1 とアクションを同じ flex 行に置き、通常の幅では一行で縦中央を揃えます。タイトルや文字拡大で収まらない場合だけ折り返し、両画面の h1・登録リンクの位置と幅を揃えます。
- `SectionHeading`: 本文のセクション見出しと補助リンクをまとめます。
- `MonthSwitcher`: 前月・翌月の 44px 操作領域と中央の月表示を提供します。
- `ActionLink`: ナビゲーション用リンクの共通部品です。`TextLink` の別名や再エクスポートは作りません。
- `RegisterTransactionAction`: `/transactions/new?month=…`、`＋` アイコン、`取引を登録` の表示、操作領域を一つに定義します。概要・取引の `PageHeader` と全ての登録用 `EmptyState` は、この部品を使います。空状態では `variant="quiet"` を使えますが、同じアイコンと表示ラベルを保ちます。
- `EmptyState`: ページ用（`page`）とセクション用（`section`）の密度を使い分けます。
- `FilterBar`: 取引画面の開閉式フィルターと、月の下に置く現在条件の概要を提供します。

取引画面のアクション群は必ず `取り込む`（`secondary`）を先に置き、`RegisterTransactionAction`（`primary`）を最後・右端に置きます。概要も登録アクションをアクション群の最後に置きます。グローバルヘッダーの `＋` だけはアイコンのみのため、`aria-label` と `title` に `取引を登録` を設定します。表示ラベルを持つ登録リンクには、同じ文言を重複する `aria-label`/`title` として付けません。

リンクは画面遷移、button はフォーム送信や開閉・状態変更に使います。表示ラベル付きの `ActionLink` は全 variant で本文サイズ・本文行間・44px の操作領域・同じアイコンサイズを共有し、variant は色・下線・ウェイトだけを変えます。

- `primary`: アクセント色、本文サイズの下線付きリンク。登録アクションの `取引を登録` ラベルを下線付きにし、先頭の `＋` アイコンは下線を付けません。
- `secondary`: muted 色の下線付きリンク。取込など主操作に次ぐ画面遷移に使います。
- `quiet`: アクセント色の下線付き補助リンク。セクション補助リンクと空状態の補助操作に使います。
- `back`: muted 色の下線付きリンク。新規・編集・取込・404 から一覧へ戻る操作に使います。

## 見出しレベル

- `h1`: ページ見出し。概要、取引、残高、新規登録、取引を編集、取込、404 の各ページで一つだけ置きます。
- `h2`: ページ内のセクション見出し。概要の支出・カテゴリ・最近の取引、取引の空状態などに使います。
- `h3`: セクション内の小見出し。概要のセクション空状態、取引の日付グループなどに使います。

月表示やフィルター条件の概要を見出しとして扱いません。

## 余白と行間

値は `apps/web/app/globals.css` の CSS カスタムプロパティで一元管理します。

| トークン            | 値     | 用途                                                                                           |
| ------------------- | ------ | ---------------------------------------------------------------------------------------------- |
| `--space-within`    | `4px`  | ラベルと入力、同一項目内の密接した要素                                                         |
| `--space-item`      | `8px`  | 同じグループ内の隣接項目                                                                       |
| `--space-group`     | `16px` | 操作群、見出しとアクション、関連グループの間                                                   |
| `--space-section`   | `24px` | セクションや取引グループの間。フィルターの条件概要から最初の日付グループまでもこの値を使います |
| `--space-page`      | `32px` | ページ開始位置、広めの空状態                                                                   |
| `--leading-tight`   | `1.15` | 大きな金額など、詰めた表示                                                                     |
| `--leading-heading` | `1.3`  | `h2` の見出し                                                                                  |
| `--leading-body`    | `1.6`  | 本文、説明、複数行の補助文                                                                     |
| `--leading-meta`    | `1.45` | `h3`、日付などのメタ情報                                                                       |

ページ幅は wide `58rem`、narrow `42rem`、import `44rem` です。日本語の本文・説明文は `--leading-body` を使い、大きな金額は見出しとは別に `--leading-tight` を使います。カテゴリ・最近の取引・取引一覧のドットは、それぞれの名前・カテゴリの先頭行に揃えます。

## 空状態

`EmptyState` は表示位置によって密度を選びます。

- `page`: ページ本文の空状態。上下 `--space-page`（32px）、左右 `--space-group`（16px）を基本にします。
- `section`: 概要など既存コンテンツ内の空状態。上下は上 `--space-section`（24px）、下 `--space-group`（16px）に詰めます。

どちらも共通の箱モチーフ、見出し、説明、登録アクションを同じ順序で持ちます。装飾を増やさず、既存の紙面・文字・罫線の表現を保ちます。

## 表示文字の間隔

画面が作る説明文・ラベルでは、日本語と ASCII の単語境界に半角スペースを一つ置きます（例: `Excel ファイル`、`5 MiB まで`）。次を例外とします。

- 金額・件数・日付などの数値と日本語のカウンター／単位（`円`、`件`、`月`、`日`）は連結します（`1,200円`、`3件`、`10月`）。
- URL、メールアドレス、識別子、ファイル拡張子などのトークン内部は書き換えません。文章中の拡張子は `.xlsx` の前後を空けます。
- 日本語の句読点・中黒・括弧の隣にはスペースを足しません（`Excel（.xlsx）`、`xlsx・5 MiB`）。
- カテゴリ名・メモ・口座名など利用者入力の保存値は、表示時にも書き換えません。
