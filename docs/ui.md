# UI レイアウト規則

## 画面の順序

月単位で表示する概要・取引画面は、次の順序を共通にします。

1. グローバルヘッダー
2. `PageHeader`（ページの `h1`、必要なら件数、右側のアクション）
3. `MonthSwitcher`
4. 画面固有の操作（取引画面では `FilterBar` と現在の絞り込み条件）
5. 本文

`MonthSwitcher` は月移動のリンクを持つ `nav` です。取引では `month`・`type`・`category`・`account`・`page` を次月・前月の URL に引き継ぎます。条件概要は折り返して横スクロールを発生させません。

取引一覧の `account` による資産の絞り込みは、通常取引の `account_id` と振替の送金元・送金先を一つの資産として扱います。削除済み資産も過去の取引を確認するため絞り込み対象にできますが、歯車の資産設定リンクは削除されていない資産に表示します。新規入力の候補には削除されていない資産（`status` が `closed` の資産を含む）を表示し、編集で既に参照している削除済み資産は保持します。

残高画面は月切替を持たず、次の順序にします。

1. グローバルヘッダー
2. `PageHeader`（ページの `h1`）
3. 残高の集計（資産・負債・純資産）
4. `kind` 順にまとめた残高一覧

残高一覧は空の種別を表示せず、保存された種別を現金・銀行・クレジットカード・デビットカード・電子マネー・その他の順で表示します。各種別の見出し行に名前と列ラベルを置き、資産行は名前を左、金額領域を右に揃えます。名前は折り返し、金額は nowrap とします。銀行は「支払予定」「残高」、設定完備のクレジットカードは「支払予定」「未請求」、過払いまたは設定から算出できないカードは「支払予定」「利用残高」のラベルを見出し行に表示します。算出できない支払予定は 0 円と区別して不明表示にし、支払日の表示は行いません。モバイルでも名前と金額領域を同じ行に置き、名前と金額を行の中央に揃えます。

集計は全期間を対象とし、未来日付の取引を含みます。初期残高は反映せず、資産未指定の取引は除外します。資産ごとの計算上の残高は `income - expense - transfersOut + transfersIn` です。0円の「その他」は分類ラベルを付けず、計算は BigInt/整数文字列で行います。モバイル幅では集計を3列（ラベル上、金額下）で表示し、純資産だけ文字の強弱で控えめに強調します。区切り線は使わず、長い金額は列を折り返して全桁を表示します。デスクトップの集計レイアウトは変更しません。

## 資産の導線と設定

資産一覧の専用ページやグローバルナビゲーション項目は持ちません。残高画面から「資産を登録」で登録し、取引一覧の資産見出し左側にある 44px の歯車（`aria-label="資産設定"`）から設定へ遷移します。設定画面からは同じ資産で絞り込んだ取引一覧へ戻れます。

資産設定フォームは名前・種別・カードの現在条件を一つにまとめます。カード条件は現在値だけを編集し、過去の条件を表示・編集する独立画面はありません。資産の削除確認は `deleted_at` を設定する論理削除だけを実行し、取引・振替・カード条件の参照を残します。保存時点で論理削除済みの資産は変更せず、保存拒否を表示します。

## 共通コンポーネントとアクション

共通部品は `apps/web/app/_components/ui.tsx` に置きます。

- `PageShell`: wide（58rem）、narrow（42rem）、import（44rem）のページ幅を提供します。
- `PageHeader`: ページの `h1` を一つだけ持ち、アクション群を右側に置きます。
- `SectionHeading`: 本文のセクション見出しと補助リンクをまとめます。
- `MonthSwitcher`: 前月・翌月の 44px 操作領域と中央の月表示を提供します。
- `ActionLink`: ナビゲーション用リンクの共通部品です。
- `RegisterTransactionAction`: `/transactions/new?month=…` と `取引を登録` の表示を定義します。
- `EmptyState`: ページ用（`page`）とセクション用（`section`）の密度を使い分けます。
- `FilterBar`: 取引画面の開閉式フィルターと、月の下に置く現在条件の概要を提供します。表示名は「資産」です。

取引画面のアクション群は必ず `取り込む`（`secondary`）を先に置き、`RegisterTransactionAction`（`primary`）を最後・右端に置きます。リンクは画面遷移、button はフォーム送信や開閉・状態変更に使います。表示ラベル付きリンクには同じ文言を重複する `aria-label`/`title` として付けません。設定歯車のようなアイコンだけのリンクは `aria-label` と `title` を付けます。

## 見出しレベル

- `h1`: ページ見出し。概要、取引、残高、資産登録、資産設定、取引編集、取込、404 の各ページで一つだけ置きます。
- `h2`: ページ内のセクション見出し。資産絞り込み、カード条件などに使います。
- `h3`: セクション内の小見出し。残高の種別グループや取引の日付グループなどに使います。

月表示やフィルター条件の概要を見出しとして扱いません。

## 余白と行間

値は `apps/web/app/globals.css` の CSS カスタムプロパティで一元管理します。

| トークン            | 値     | 用途                                   |
| ------------------- | ------ | -------------------------------------- |
| `--space-within`    | `4px`  | ラベルと入力、同一項目内の密接した要素 |
| `--space-item`      | `8px`  | 同じグループ内の隣接項目               |
| `--space-group`     | `16px` | 操作群、見出しとアクション             |
| `--space-section`   | `24px` | セクションや取引グループの間           |
| `--space-page`      | `32px` | ページ開始位置、広めの空状態           |
| `--leading-tight`   | `1.15` | 大きな金額など、詰めた表示             |
| `--leading-heading` | `1.3`  | `h2` の見出し                          |
| `--leading-body`    | `1.6`  | 本文、説明、複数行の補助文             |
| `--leading-meta`    | `1.45` | `h3`、日付などのメタ情報               |

ページ幅は wide `58rem`、narrow `42rem`、import `44rem` です。日本語の本文・説明文は `--leading-body` を使い、大きな金額は `--leading-tight` を使います。

## 金額の色

金額は `SignedYen`／`moneyTone`／`moneyToneClass` で符号または収支方向から色を決め、概要・残高・取引一覧・取込・振替で同じ規則を使います。正数・収入は青、負数・支出は赤、0円と振替は通常のインク色です。資産・負債の集計はラベルの意味を優先し、純資産と資産行の残高は値の符号に従います。色だけに依存せず、`＋`／`−` とスクリーンリーダー用の符号も残します。

## 空状態

`EmptyState` は表示位置によって `page` と `section` の密度を使い分けます。残高の空状態は「表示する資産がありません」とし、説明と「資産を登録」リンクを同じ順序で持ちます。装飾を増やさず、既存の紙面・文字・罫線の表現を保ちます。

## 表示文字の間隔

画面が作る説明文・ラベルでは、日本語と ASCII の単語境界に半角スペースを一つ置きます（例: `Excel ファイル`、`5 MiB まで`）。カテゴリ名・メモ・資産名など利用者入力の保存値は、表示時にも書き換えません。

残高一覧は銀行・クレジットカードともに、資産名の右側を二列の金額領域として揃え、見出し行と各資産行で列幅・間隔・右端を共有します。銀行の「支払予定」は、設定完備カードのうち同じ銀行を引落口座に指定した全カードについて、当月に支払日を迎える締め済み未払い分の残額を合計します。該当カードがない銀行も 0 円を表示します。

設定完備のクレジットカードは、「支払予定」に締め済み未払い（`billed-unpaid`/`overdue`）の全期間の残額、「未請求」に締め前（`unbilled`）の全期間の残額を表示します。過払いなどでカードの実残高が信用（負数）になった場合は、信用を隠さず右列を「利用残高」として表示し、同じラベルのカードを別の見出し行にまとめます。設定済みで該当する残額が 0 円の場合も支払日の表示はしません。

クレジットカード設定がないカード、または設定行が不完全・不正なカードは、「支払予定」を不明表示にし、右列に実残高を「利用残高」として表示します。これらは過払いカードと同じ「支払予定」「利用残高」の見出し行にまとめます。請求期間の詳細、専用フィルター、請求セクション、支払専用画面は追加せず、カード名から既存のカード別取引一覧へ移動します。
