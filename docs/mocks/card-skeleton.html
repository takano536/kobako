資産編集のカード条件

カテゴリが届くまで、4行の節があるか分からない。

骨組みの既定非カード（264px）クレジットカード（509px）
2行（条件なし） 264 = 264
差 0		 264 → 509
245px不足
6行（節を確保） 509 → 264
245px余り		 509 = 509
差 0

推奨: 2行を既定。カード条件は追加の節なので、読み込み後に下へ伸びる方が、非カードに空の節を見せるより自然です。カードのときの245pxの伸びを許容するか、カードだけ6行の骨組みを使うかを決めます。
現状の骨組みは4行・438px。非カードには174px高く、クレジットカードには71px低い。

レシピ

新しいカードは、行の並びと左の操作を足すだけ。

// 行の部品
const transactionRows = ['choice', 'amount', 'field', 'field', 'field', 'field'];
const fixedCostRows  = ['field', 'amount', 'field', 'field', 'field', 'field'];
const assetRows      = ['field', 'field'];
const cardConditionRows = ['section', 'field', 'field', 'field', 'field'];

// 7つの loading.tsx（取引の新規・編集・振替編集は同じ並び）
<CardFormSkeleton label="取引を読み込み中" rows={transactionRows} action="cancel" />
<CardFormSkeleton label="取引を読み込み中" rows={transactionRows} action="delete" />
<CardFormSkeleton label="固定費を読み込み中" rows={fixedCostRows} action="cancel" />
<CardFormSkeleton label="固定費を読み込み中" rows={fixedCostRows} action="delete" />
<CardFormSkeleton label="資産を読み込み中" rows={assetRows} action="cancel" />
<CardFormSkeleton label="資産を読み込み中" rows={assetRows} action="delete" />

// 資産編集でカード条件まで確保する場合（推奨は既定2行）
<CardFormSkeleton
  label="資産を読み込み中"
  rows={[...assetRows, ...cardConditionRows]}
  action="delete"
/>

数値は実フォームの実測とCSSから（440px幅、ヘッダー60px、行53px）。カード条件の節は、4行212px＋見出しと余白33px＝245px、カードは509px。現状の骨組みは全カード438pxです。
