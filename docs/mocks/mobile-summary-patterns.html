モバイル「概要」サマリー — 5案

内容列 358px。支出の大きさは変えずに、収入と収支差額の置き方だけを振っています。どれも金額は左揃えです。

1. 一行（デスクトップと同じ形）

概要

この月の支出186,800円
収入
328,000円
収支差額
141,200円

縦が一番短い。画面をまたいでも形が同じ。ただし 358px では文字を小さく落とすので、収入・差額がかなり控えめになる。

2. 2行リスト（値は固定列）

概要

この月の支出186,800円
収入
328,000円
収支差額
141,200円

読み順が素直。ラベルと金額が同じ行に並ぶので、視線が上下に往復しない。罫線を足さないぶん軽い。

3. 罫線つきリスト

概要

この月の支出186,800円
収入
328,000円
収支差額
141,200円

表として読める。行の区切りがはっきりして、金額の列も揃う。罫線が2本増えるぶん、下のセクションと重く見える可能性。

4. 1行メタ

概要

この月の支出186,800円
収入
328,000円
収支差額
141,200円

主役を一つに絞る。支出だけを見せて、収入と差額は補足行に。情報量は同じだが、優先順位がいちばん明確。

5. いまの案（2列セル）

概要

この月の支出186,800円
収入
328,000円
収支差額
141,200円

比較用。2列に割るので右が空く。金額が縦に揃うが、支出とのつながりは弱い。
